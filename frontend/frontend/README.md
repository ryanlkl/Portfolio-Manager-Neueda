# Portfolio Manager

## Overview
This project is a Portfolio Manager application that allows users to manage their investment portfolios. Users can view their portfolio overview, including stock data and performance charts, and manage their assets.

## Features
- **Portfolio Overview**: Displays an overview of the user's portfolio, including stock data and historical performance.
- **Add Assets**: Users can add new assets to their portfolio through a dedicated form.
- **User Accounts**: Displays user details and account information.

## File Structure
```
frontend
├── src
│   ├── pages

│   │   └── accounts.jsx        # Component for displaying user details

│   ├── css                      # Stylesheets for the application
│   └── lib                      # Utility functions and custom hooks
├── package.json                 # NPM configuration file
└── README.md                    # Documentation for the project
```

## Installation
To install the project dependencies, run the following command in the project root directory:

```
npm install
```

## Usage
To start the development server, use the following command:

```
npm start
```

Visit `http://localhost:3000` in your browser to view the application.
